Objetivo: Definir a aplicação base da equipe e consolidar o fluxo de trabalho em equipe no GitHub.

Descrição da Atividade:
    1 - Definição do Sistema: O grupo de até 4 alunos deve escolher ou criar uma aplicação simples (web/mobile) que servirá de base durante as próximas atividades da disciplina (Não precisa ser um sistema inteiro, pode ser algo simples como uma tela de cadastro de conta e outra de login funcionando). 
    2 - Criação do Repositório: Criar um repositório no GitHub para o projeto (público para eu ter acesso).
    3 - Prática de Git em Equipe:
        # Cada um dos 4 integrantes deve criar sua própria branch para trabalhar em uma parte do código.
        # Os alunos devem enviar alterações via commits e abrir Pull Requests (PRs) direcionados à branch principal (main).
        # Cada PR deve ser revisado (code review) e aprovado por outro colega de grupo antes do merge.

Entregável:
    # Documento (PDF/Word) descrevendo a aplicação com pelo menos uma imagem do projeto.
    # Ter o nome dos membros da equipe
    # Link do repositório público ou convite de acesso.
    # Evidências visuais (prints) da aba de Pull Requests
